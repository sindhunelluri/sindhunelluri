## 🧠 Transformer-Based Melanoma Detection Using Deep Learning

### 📌 Description
Developed an AI-powered web application for the early detection of melanoma from dermoscopic skin images using a **Vision Transformer (ViT)** model. The project leverages transfer learning, image preprocessing, and data augmentation techniques to accurately classify skin lesions as **Melanoma** or **Non melanoma**, supporting early diagnosis and improving healthcare decision-making.

### ✨ Key Features
- 🔬 Vision Transformer (ViT) based deep learning model
- 🖼️ Image preprocessing and data augmentation
- 📊 Binary classification of skin lesions
- 🌐 User-friendly web interface
- ⚡ Fast and accurate prediction results

### 🛠️ Tech Stack
- **Programming Language:** Python
- **Deep Learning:** PyTorch
- **Model:** Vision Transformer (ViT)
- **Libraries:** NumPy, Pandas, OpenCV
- **Frontend:** HTML, CSS, JavaScript

### 🔗 Links
